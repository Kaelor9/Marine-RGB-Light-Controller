PRISM INSTALLER – KORT VEJLEDNING

Denne pakke skaber et rigtigt HTTPS-installerlink via GitHub Pages.

1. Udpak ZIP-filen.
2. Opret repositoryet "prism-installer" på GitHub.
3. Upload alt indholdet fra den udpakkede mappe.
4. Gå til Settings -> Pages -> Source -> GitHub Actions.
5. Når Actions er grøn, åbnes:
   https://DIT-BRUGERNAVN.github.io/prism-installer/

På installer-siden:
- Tilslut ESP32 med USB.
- Brug Chrome eller Edge.
- Tryk "Installér Prism".
- Vælg COM-porten.
- Konfigurér Wi-Fi via netværket "Prism Setup".

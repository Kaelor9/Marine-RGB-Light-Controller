Installation

Three simple steps

Connect the controller, install the firmware and complete the wireless setup. The complete process normally takes only a few minutes.

01

Connect

Connect the controller to your computer using a USB-C data cable. Charging-only cables cannot transfer firmware.

02

Install

Select Install Firmware, choose the controller from the USB device list and confirm the installation.

03

Configure

After installation, connect to Marine RGB Setup, select your Wi-Fi network and complete the configuration.

⚠ Installing the firmware erases the program currently stored on the controller. Existing firmware and locally stored settings may be overwritten.

Troubleshooting

No device appears: Check that the USB cable supports data and reconnect the controller.

Installation fails: Close programs that may already be using the controller's serial port.

Controller does not enter installation mode: Hold the BOOT button while briefly pressing RESET, then try the installer again.

Marine RGB Light Controller

Firmware Installer

Seneste firmware ESP32-S3 USB-C

Installér den seneste firmware direkte fra browseren. Du behøver ikke Arduino IDE eller andre programmer.

Installér firmware

Tilslut controlleren med et USB-datakabel, og start installationen.

Denne browser understøtter ikke USB-programmering. Åbn siden i Chrome eller Microsoft Edge på en computer. Browseren har blokeret USB-adgangen. Kontrollér, at siden er åbnet via HTTPS.

Kræver Chrome eller Microsoft Edge på Windows, macOS eller Linux.

Sådan gør du

1

Tilslut controlleren

Brug et USB-C-datakabel. Et kabel, der kun understøtter opladning, kan ikke bruges.

2

Start installationen

Tryk på Tilslut og installér, og vælg controllerens USB- eller COM-port.

3

Konfigurer Wi-Fi

Efter genstart forbindes du til Marine RGB Setup. Vælg derefter dit lokale Wi-Fi-netværk.

⚠ Installationen overskriver den firmware, der allerede ligger på controlleren. Gem eventuelle indstillinger, før du fortsætter.
